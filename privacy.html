home-agent privacy policy

Last updated 30 October 2026

home-agent is a private tool used by one household. Its only user is the owner of the Google account that signs in to it. This policy says what it does with Google user data.

What it accesses

  • Gmail messages from a short list of senders the owner chose (shops, banks, school), to file them.
  • Gmail labels and filters, to sort those messages in the owner's own mailbox.
  • Google Calendar events, only to add an event after the owner confirms it.

How it uses and stores the data

The data is processed and stored only on the owner's own computer at home. It is used only to give the owner the features above. It is not sold, not shared with anyone, not used for advertising, and not used to train AI or machine learning models. No person other than the owner reads it.

Limited Use

home-agent's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access and data

The owner can remove home-agent's access at any time at myaccount.google.com/permissions. Data already stored stays on the owner's own computer, where the owner can delete it.

Contact

Questions about this policy can be raised through the issues page of the repository that hosts this site.
